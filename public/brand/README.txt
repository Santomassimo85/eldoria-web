CRIT HAPPENS — Pacchetto logo
=============================

Tutti i testi sono convertiti in TRACCIATI vettoriali: gli SVG si vedono
identici ovunque, senza bisogno di installare font.

Palette
-------
Gradiente brand : #8B3DF5  ->  #D63AD0  (viola -> magenta)
Viola scuro     : #3F1296   (ombra "CRIT")
Bordo dado      : #5A2BC0
"1"             : #1E1145 (logo) / bianco su tile (favicon piccolo)
Font            : Cinzel (Google Fonts) — già in outline nei file

NOTE
----
- Per esportare altri formati (PDF, EPS, WebP) o nuove misure, parti SEMPRE dagli .svg.
- Il logo a colori funziona sia su fondo chiaro sia scuro.
- Spazio di rispetto consigliato attorno al logo: almeno mezza altezza dell'icona.
